# EduPath AI (Streamlit prototype)

AI-Based Personalized Learning Recommendation System, Semester V project.
All recommendation scores are simulated from sample data. No ML model is trained.

## Run locally
    pip install -r requirements.txt
    streamlit run app.py

## Deploy from GitHub (Streamlit Community Cloud)
1. Create a GitHub repository and upload app.py, requirements.txt and the .streamlit folder to the repository root.
2. Go to share.streamlit.io and sign in with GitHub.
3. Click Create app, pick your repository and branch, and set Main file path to app.py.
4. Click Deploy.
